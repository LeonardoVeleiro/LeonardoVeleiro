## 📌 Projeto em destaque

### Mission Control API + Mobile

Sistema integrado para controle de missão espacial, desenvolvido com backend em **Java Spring Boot** e aplicativo mobile em **React Native com TypeScript**.

O projeto foi desenvolvido como trabalho acadêmico e simula uma solução para controle de missão espacial, permitindo o cadastro e a consulta de dados relacionados a sensores, sistemas monitorados, eventos operacionais e alertas críticos.

Principais recursos:

- API REST com Spring Boot
- Banco de dados H2 em modo file
- Endpoints com requisições GET e POST
- Cadastro e listagem de sensores
- Cadastro e listagem de sistemas monitorados
- Cadastro e listagem de eventos operacionais
- Cadastro e listagem de alertas críticos
- Aplicativo mobile integrado ao backend
- Interface para cadastro e visualização de sensores
- Documentação no README do projeto

🔗 Repositório: [Mission Control API + Mobile](https://github.com/LeonardoVeleiro/missioncontrol)
